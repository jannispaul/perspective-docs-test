Tools

📄️Funnels

MCP tools for creating and editing Perspective funnels with AI generation — create, update content, update metadata, and track async jobs.

📄️Sequences

MCP tools for building and managing Perspective email sequences — create, update, publish, unpublish, and read step HTML.

📄️Brands

MCP tools for reading and creating Perspective brand profiles — list brands, fetch a single brand, and generate a new brand from a domain or description.

📄️Domains and Senders

MCP tools for listing the publishing domains and email sender identities available on a Perspective account.

📄️Metrics

MCP tools for querying Perspective funnel analytics — KPI values, chart data, survey insights, and the full metric catalog.

📄️CRM

MCP tools for reading Perspective CRM contacts and contact schema — list contacts, get a single contact, and fetch field definitions.

📄️Sequence Stats

MCP tools for querying email delivery statistics and event logs across Perspective sequences and funnels.

📄️Workspaces

MCP tool for listing all Perspective workspaces and their funnels — the primary way to discover funnel IDs for other tools.
